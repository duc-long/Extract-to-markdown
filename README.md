# Extract to Markdown

A powerful web application designed to extract content from various document types and convert them into clean, editable Markdown format. 

## Key Features

- **Multi-format Support:** Seamlessly convert PDF, Word (`.docx`), Excel (`.xlsx`), and Image files into Markdown.
- **Multilingual Support:** Accurately extract text across multiple languages including English, Vietnamese, Chinese, Korean, and Japanese.
- **High Accuracy:** Intelligently extracts complex document structures, including tables, text formatting, and mathematical equations.
- **Live Preview:** View the generated Markdown instantly in your browser before downloading.

## Privacy & Security

- **100% Local Processing:** All file processing and text extraction happens locally on your machine.
- **No Data Collection:** Your documents are never uploaded to any external servers, ensuring complete privacy and data security.

## Getting Started

### Prerequisites

- Node.js (version 18 or higher recommended)

### Installation

1. Install the required dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser and navigate to the local URL provided in the terminal to start using the app.
